# StudyGotchi

HackMIT prototype: a clickable **living knowledge world** UI.

```bash
cd web
npm install
npm run dev
```

Open http://localhost:5173 — any email/password logs in. Use an email containing `2fa` and code `123456` for the two-factor mock.

See `web/` for the frontend; `course-materials/` holds sample class zips.
