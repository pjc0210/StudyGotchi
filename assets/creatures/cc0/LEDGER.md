# CC0 / CC-BY creature asset ledger

Only CC0 (public domain) or CC-BY licensed assets are allowed in `assets/creatures/cc0/`. Anything with a stricter license (CC-BY-SA, CC-BY-NC, proprietary, "free for personal use", unverifiable) must NOT be downloaded here. CC-BY items must have the exact attribution text recorded in the `notes` column, and that text must be reproduced in the game's credits. Each row is written BEFORE the download is attempted, so a failed download still leaves provenance (`downloaded file` = `FAILED: <reason>`). Paths in `downloaded file` are relative to `assets/creatures/cc0/`.

Gobkit shared facts (from `https://gobkit.com/api/free`, saved as `gobkit/api-free.json`): the response has no separate license URL field, so the license URL column uses `https://gobkit.com`; every GLB additionally carries `asset.copyright = "CC0-1.0 — https://creativecommons.org/publicdomain/zero/1.0/"`. API `usage.license`: "CC0 1.0 (public domain) - free for any use, commercial or personal, no attribution required." API `usage.loading`: "For PRODUCTION use, download the pack zip (or individual .glb files) and bundle them INTO your project - CC0 license allows free redistribution, and your game then has zero runtime dependency on gobkit.com. Hotlinking these URLs at runtime is fine for quick prototypes/demos only." API `usage.animation`: rigged packs ship ONE master clip; slice with `THREE.AnimationUtils.subclip(gltf.animations[0], name, from, to+1, 24)`; spawn copies with `SkeletonUtils.clone`. Models face +Z, up +Y, units in meters.
