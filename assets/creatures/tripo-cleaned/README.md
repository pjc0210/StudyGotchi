# Tripo cleaned creature assets

48 creatures, each in two animated GLB variants. Use `textured/` to preserve the original appearance; this requires preserving the color map during StudyGotchi's material replacement. `toon/` provides five flat colors compatible with the existing replacement, with reduced facial detail.

All textures in the textured variant are declared here: each GLB embeds a single 512 × 512 PNG color atlas. There are no external texture files to resolve.

Read the package's `START-HERE.md` for the exact integration steps, validation results, limitations, and reference-only source status. The full handoff is also installed in this folder's `handoff/` directory in the StudyGotchi checkout.
