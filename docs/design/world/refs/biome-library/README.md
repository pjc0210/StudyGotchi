# Final world reference library

This folder contains the selected visual references for the current world roster. Alpine is intentionally excluded as a separate world. Meadow has been merged into the medieval kingdom. The volcanic world is framed as expansive Nordic highlands and fjord villages, with lava used as a secondary accent.

## Intended use

Use these as a reference pool, not as eleven fixed map templates. Each generated map should select a different mix of terrain silhouettes, landmark types, paths, vegetation, architecture, color accents, and density. Spread borrowed ideas across the map instead of reproducing any single image as one contiguous region.

The MIT folder includes official maps plus official MIT photographs of recognizable campus landmarks. `SOURCES.tsv` records the source page for every reference. Pinterest and third-party images are retained for private visual reference only.
