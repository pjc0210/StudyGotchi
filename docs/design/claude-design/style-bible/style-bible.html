StudyGotchi · Style bible · 01

Toybox Low-Poly, in one line

Two registers that never mix. The world is chunky faceted 3D with no outlines and soft 3-step shading. The UI on top of it is a flat sticker: thick ink outline, cream fill, rounded, calm. Below, what each reference contributes.

Tile dioramas
Pedestal cliffs, one hero landmark per patch, 3-step shading, zero outlines. Our patch unit.
Toy creatures
Facets as a feature. Big head, tiny limbs, one saturated colour each, matte surfaces.
Low-poly animals
Lowest polygon budget we accept. Silhouette carries the species, not the detail.
Blob archetype
Dot eyes, flat mouth, no eyebrows. The face template for every blob and bean creature.
Bird archetype
A single faceted ball, a wedge beak, stick legs. Under 60 faces and still a kiwi.
Bean archetype
Loaf body, flat disc ears, pea nose. Two colours plus black. The bean body we use for rodents.
Sticker register (2D)
Thick dark-brown outline, flat fills, one belly highlight. This is the UI, never the 3D.
Soft-toy texture
Felt-like matte, pastel, deadpan faces. Tone reference for creature personalities.
Layered island
Stacked cake tiers with a crumbly rim. When a concept is demonstrated the ground rises like this.
Density and life
Many tiny creatures wandering, floating shelves, fog at the horizon. Target for a mature world.
Calm and colour
One flat sky, warm ground, cool water. Restraint reference: the world is never busy in colour.
Landmark progression
Isometric 3/4 view, one readable silhouette per object. Structure reference only, not the render style.

Rules
Sentence case everywhere except the label style. No italics. Numbers use tabular figures (6.1210 · 18.06 · 72%) so rings and counters do not jitter.
Course numbers are set in the same face, never monospace. Creature names get h3, never display.

StudyGotchi · Style bible · 05

The sticker rule, and the parts built from it

Every 2D element that can be pressed, picked, or read as a status wears a 3 px ink outline (#3a2f45), a flat fill, and a rounded corner. Over the 3D canvas, only interactive elements get the outline; the panels behind them are glass. On full pages (landing, sign-in, My worlds) panels get the outline too.

Buttons
Primary is ink-filled. Secondary is cream with a 3 px hard drop (a sticker lifted off the page); pressed removes the drop and moves down 3 px. Ghost has no outline and is only for tertiary actions inside a card. Min height 44 px.

StudyGotchi · Style bible · 06

Icons

24 px grid, 2.5 px ink stroke, round caps and joins, one readable silhouette, no text inside an icon. Filled variants use a semantic colour with the same ink stroke on top, so an icon is a small sticker.

Rules
Three semantic icons (sprout, landmark, creature) are the only filled ones; everything else is a bare stroke on cream.
Sizes: 16 inside chips, 22 in buttons and banners, 32 on tiles. Never scale below 16.
No letters, digits, or symbols inside an icon. A course is its number in type, not a glyph.
Icon-only buttons need an aria-label. Icons never replace the state badge; they sit next to it.
Export as SVG with stroke set to currentColor so Tailwind text colour drives them.

StudyGotchi · Style bible · 08

Motion

Bold held poses. Anything that appears pops in with an overshoot. Anything idle bobs. Nothing anticipates, nothing eases in slowly, nothing in the UI takes longer than 400 ms. Press the buttons.
