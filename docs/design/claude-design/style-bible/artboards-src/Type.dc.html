Rules
Sentence case everywhere except the label style. No italics. Numbers use tabular figures (6.1210 · 18.06 · 72%) so rings and counters do not jitter.
Course numbers are set in the same face, never monospace. Creature names get h3, never display.
Max line length 64 characters. Body never below 14 px in UI, never below 12 pt in print.
Voice
Deadpan and warm. State facts, do not cheer.
