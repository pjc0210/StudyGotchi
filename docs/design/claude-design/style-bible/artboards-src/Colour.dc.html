Colour

Five biomes, each a ground and an accent. The 3D world gets the three-step ramp (light, base, shade) with hard steps and no gradients. The UI gets the flat base only.

Ramp rule for Blender and the toon shader: light = base +14 L, shade = base −14 L, same hue, no black in shadows. Bands snap, never blend.
