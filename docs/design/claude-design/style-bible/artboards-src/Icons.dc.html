Icons

24 px grid, 2.5 px ink stroke, round caps and joins, one readable silhouette, no text inside an icon. Filled variants use a semantic colour with the same ink stroke on top, so an icon is a small sticker.

Rules
Three semantic icons (sprout, landmark, creature) are the only filled ones; everything else is a bare stroke on cream.
Sizes: 16 inside chips, 22 in buttons and banners, 32 on tiles. Never scale below 16.
No letters, digits, or symbols inside an icon. A course is its number in type, not a glyph.
Icon-only buttons need an aria-label. Icons never replace the state badge; they sit next to it.
Export as SVG with stroke set to currentColor so Tailwind text colour drives them.
